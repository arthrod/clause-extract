# clause-extract level-tuning loop — single turn

Your job in this turn is to tune `parse_doc2dict_with_config.py` (or the
mapping config it depends on) so that ONE source agreement parses with
levels that match the rubric below — without breaking any previously
frozen samples.

Each turn has fresh context. There is no memory between turns. Read the
state, make the minimal change, freeze, advance, exit.

## Level rubric (the contract)

Levels are 0-indexed depths in the parsed tree. For a typical
EX-10 agreement (e.g. an Indemnification Agreement) the expected mapping is:

  - Level 0  →  the agreement itself (single root). For an
                "INDEMNIFICATION AGREEMENT" doc, the agreement's title
                line and its preamble paragraph.
  - Level 1  →  top-level headings and recital blocks: party / exhibit
                metadata ("ULURU Inc.", "EXHIBIT 10.25"), the
                WITNESSETH/WHEREAS recitals, the signature block.
  - Level 2  →  numbered Sections: "1.", "2.", "10.", "Section 1.1".
  - Level 3  →  lettered subsections: "(a)", "(b)", "(c)".
  - Level 4  →  sub-sub items: "(i)", "(ii)", "(A)", "(B)", "(1)", "(2)".

Heading + body for a section are emitted as ONE record with `level` set
to the heading's depth and `span` = "<heading>\n<body_direct>".

## Workflow for THIS turn

1. Read the source-of-truth and the current output above. Decide which
   minimal edit to `clause-extract/scripts/parse_doc2dict_with_config.py`
   or `clause-extract/src/clause_extract/agreement_config.py` makes the
   levels for idx=0 match the rubric.

2. Make the edit. Keep it minimal — adding/tightening one regex,
   reshaping the per-level pattern list. Do NOT refactor unrelated code.

3. Re-run the parser on idx=0:

     uv run scripts/parse_doc2dict_with_config.py \
       --limit 1 \
       --output-dir data/auto_parse \
       --no-truncate

   (Run from the repo root. `--limit 1` parses idxs 0..0
   inclusive. `--no-truncate` keeps full spans so the freeze captures the
   real text.)

4. Inspect the output for idx=0 in
   `data/auto_parse/parse_doc2dict_with_config_nodes.jsonl`. Verify the
   levels match the rubric.

5. If correct, freeze:

     uv run scripts/level_loop/freeze.py 0

6. Run the regression check:

     uv run scripts/level_loop/regress.py

   If this fails, your change broke a previously frozen idx. Loop back to
   step 2 and find a smaller change. Do NOT advance until regress is clean.

7. Advance to the next sample:

     uv run scripts/level_loop/advance.py

   `advance.py` re-runs `regress.py` itself as a gate; it will refuse if
   anything fails. Do not call advance with --skip-regress.

When advance succeeds, your turn is done. Print a one-line summary of
what changed and which idx is next, then stop.

## Hard rules

- Edit only `parse_doc2dict_with_config.py` and/or `agreement_config.py`
  unless the rubric clearly requires changes elsewhere.
- Never edit files under `data/auto_parse/level_freeze/frozen/` by hand.
- Never call `freeze.py --force` unless you are explicitly fixing a
  bad freeze — the loop driver will tell you if so.
- If you cannot make the levels match without breaking a frozen idx,
  STOP, print why, and exit. The human running the loop will decide.
