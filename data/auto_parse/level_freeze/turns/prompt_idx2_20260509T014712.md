# clause-extract level-tuning loop — single turn

Your job in this turn is to tune `parse_doc2dict_with_config.py` (or the
mapping config it depends on) so that ONE source agreement parses with
levels that match the rubric below — without breaking any previously
frozen samples.

Each turn has fresh context. There is no memory between turns. Read the
state, make the minimal change, freeze, advance, exit.

## Level rubric (the contract)

Full canonical rubric: `task_rules/level_rubric.md`. Worked examples:
`task_rules/examples_main_agreement.md`,
`task_rules/examples_with_subdocs.md`. Skim them before editing.

Summary — levels are 0-indexed depths into the agreement's structural
hierarchy:

  - Level 0  →  the agreement itself (single record per idx): title
                line + preamble paragraph.
  - Level 1  →  top-level headings and recital blocks: party metadata
                ("ULURU Inc."), the WITNESSETH/WHEREAS recitals, the
                signature block, the FIRST line of subdocument headers.
  - Level 2  →  numbered Sections: "1.", "2.", "10.", "Section 1.1".
  - Level 3  →  lettered subsections: "(a)", "(b)", "(c)".
  - Level 4  →  sub-sub items: "(i)", "(ii)", "(A)", "(B)", "(1)", "(2)".
  - Level 5+ →  ONLY appears inside attached subdocuments (see below).

Heading + body for a section are emitted as ONE record with `level` set
to the heading's depth and `span` = "<heading>\n<body_direct>".

### SEC envelope drop

The FIRST line of every SEC EX-10 filing is an exhibit number like
"EXHIBIT 10.25" — that's filing metadata, not contract content. The
parser drops it from JSONL (kept in parquet via `is_envelope=true`).
You should see NO "EXHIBIT <number>" record as the first JSONL row.

### Subdocument penalty

A real subdocument is an attached doc inside the main contract — e.g.
"EXHIBIT A — FORM OF NOTICE", "SCHEDULE 1 — DEFINITIONS", "ANNEX I".
These appear AFTER the main contract body. Each level of subdoc nesting
adds **+1** to every descendant's level.

So "(a)" inside one subdoc → level 4 (3 + 1). "(i)" inside an annex
nested in a schedule nested in the main agreement → level 7
(4 + 3 penalties). Levels 5–7 should ONLY appear when the document
actually has subdocuments.

The SEC envelope (the FIRST `cls=exhibit/schedule/appendix/annex`
section per idx) is NOT a subdocument — its descendants are the main
contract and get penalty=0.

## Workflow for THIS turn

1. Read the source-of-truth and the current output above. Decide which

2. Make the edit. Keep it minimal — adding/tightening one regex,
   reshaping the per-level pattern list. Do NOT refactor unrelated code.

3. Re-run the parser on idx=2. The `--output-dir` MUST be the
   ABSOLUTE path `/Users/arthrod/temp/T/clause-extract/data/auto_parse` — that is the canonical directory the
   freeze and regress scripts read. Using a relative path will write
   somewhere else (the repo has nested `clause-extract/clause-extract/`)
   and the freeze will silently capture stale output.

     cd /Users/arthrod/temp/T/clause-extract/clause-extract && \
       uv run scripts/parse_doc2dict_with_config.py \
         --limit 3 \
         --output-dir /Users/arthrod/temp/T/clause-extract/data/auto_parse \
         --no-truncate

   `--limit 3` parses idxs 0..2 inclusive. `--no-truncate`
   keeps full spans so the freeze captures real text. Confirm the parser
   wrote to /Users/arthrod/temp/T/clause-extract/data/auto_parse/parse_doc2dict_with_config_nodes.jsonl by
   checking its mtime is recent — `ls -la` it before freezing.

4. Inspect the output for idx=2 in
   `data/auto_parse/parse_doc2dict_with_config_nodes.jsonl`. Verify the
   levels match the rubric.

5. If correct, freeze:

     uv run scripts/level_loop/freeze.py 2

6. Run the regression check:

     uv run scripts/level_loop/regress.py

   If this fails, your change broke a previously frozen idx. Loop back to
   step 2 and find a smaller change. Do NOT advance until regress is clean.

7. Advance to the next sample:

     uv run scripts/level_loop/advance.py

   `advance.py` re-runs `regress.py` itself as a gate; it will refuse if
   anything fails. Do not call advance with --skip-regress.

When advance succeeds, your turn is done. Print a one-line summary of
what changed and which idx is next, then stop.

## Hard rules

- Edit only `parse_doc2dict_with_config.py` and/or `agreement_config.py`
  unless the rubric clearly requires changes elsewhere.
- Never edit files under `data/auto_parse/level_freeze/frozen/` by hand.
- Never call `freeze.py --force` unless you are explicitly fixing a
  bad freeze — the loop driver will tell you if so.
- If you cannot make the levels match without breaking a frozen idx,
  STOP, print why, and exit. The human running the loop will decide.
